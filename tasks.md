# Tasks - Recipe Explorer

 **Task 1: Project Setup and Initial Mock Data Display**
  - **Done when:** The React + Vite app runs without console errors and renders an initial list of recipes from a local JSON file (`mockRecipes.json`).

**Task 2: Modular Component Breakdown and Master-Detail Implementation**
  - **Done when:** The application is split into at least 4 separate components (`Header`, `RecipeList`, `RecipeCard`, `RecipeDetail`), and clicking any recipe card displays its details in the side panel.

**Task 3: Live API Integration with Fetch and useEffect**
  - **Done when:** The app fetches live data from TheMealDB API, replacing the mock JSON file, with clear loading ("Loading...") and error states rendered on screen.

 **Task 4: Search and Filter Functionality**
  - **Done when:** Typing in the search input filters the displayed recipe list in real time by meal name.

**Task 5: Responsive Styling and Mobile Layout**
  - **Done when:** Custom CSS provides an organized layout that adapts cleanly to both wide desktop screens and narrow mobile viewports.

**Task 6: Project Documentation and Final Verification**
  - **Done when:** A complete `README.md` is present detailing project functionality, execution steps, and API usage, with all console errors resolved.
